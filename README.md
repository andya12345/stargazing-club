# 星空社 · 上海市育才中学天文社团

一个纯静态宣传页面。首屏是一段开场动画：黑场 → 银河 → 推近 → 太阳系，之后行星按真实轨道周期持续运转。
**没有构建步骤、没有外部依赖**，双击 `index.html` 就能看。

---

## 一、怎么打开

- 直接双击 `index.html`（推荐 Chrome / Edge，Firefox / Safari 也可以）
- 或用任意静态服务器托管，例如 VS Code 的 Live Server
- 手机上打开同目录页面同样可用（已做响应式）

---

## 二、首屏动画是什么

**WebGL2 实时渲染的 3D 场景**（`assets/js/cosmos.js`），不用一张图片、不加载任何外部资源。

1. **纯黑开场** → 银河全貌（四旋臂、核球、旋臂上的星云）
2. **俯冲**：镜头斜着扎进星盘外侧，恒星被拉成一条条速度线从身边掠过
3. **抵达**：落到盘面上一颗恒星前，它亮起来
4. **展开**：太阳系在这颗星周围显形（没有白光闪切，是渐显）
5. **持续**：八大行星按真实轨道周期公转

### 可以手动控制

和 `galaxy-to-solar` 那个文件一样，转场由进度 `p` 驱动，自动播放时也能随时接管：

| 操作 | 效果 |
|---|---|
| 滚轮 / 触控板 | 前进后退 |
| 鼠标按住上下拖 | 拖动进度 |
| ↑ ↓ / 空格 / PageUp PageDown | 步进 |
| Home / End | 回到开头 / 直接到结尾 |

没有加任何文字提示。**放完之后还能往回滚**：页面在顶部时，向上滚会退回动画（向下滚才会滚页面）。
松手 2.4 秒后会自己接着往下放；退回去的时候，右侧文字也会跟着淡出，回到原来的空镜。

### 渲染细节

- 场景渲进 **RGBA16F 的 HDR 帧缓冲**，泛光：亮部提取 → 两次高斯模糊 → 叠加
- **恒星拖尾**：每颗星画成一条「这一帧位置 ↔ 上一帧位置」的线段，镜头一动就自然拉出速度线，静止时自动消失
- **ACES 电影色调映射** + 暗角 + 极轻胶片颗粒
- **星云**：3D 广告牌 + 运行时生成的噪声贴图，沿旋臂分布
- **行星**：球面网格 + 程序化着色（岩石 / 地球 / 气态巨行星 / 冰巨星）
- **背景星空**：太阳系后面铺了 2600 颗星的穹顶，其中有银河带聚集
- **太阳系细节**：轨道的近端比远端亮（深度感）、火星木星之间的小行星带、行星带自身颜色的光晕、太阳日冕和一道很淡的横向镜头光斑
- 落地之后行星**继续公转**，不是定格

### 关于「真实星表」

本来想直接嵌入真实星表（d3-celestial 的 `stars.6.json`，656 KB / 约 9000 颗），但这份文件超出了我这边的取数通道限制（单次约 100 KB），只拿到前 800 颗，是按赤经排序的一小片天空，用上去只会一半天上没星星，所以暂时用了**按真实亮度分布生成的星空**。

已经留好了接口：在 `index.html` 里 `cosmos.js` **之前**加一行脚本，定义

```js
window.REAL_STARS = [[raDeg, decDeg, mag, bv], ...];
```

太阳系的背景星空就会换成真实星表（`bv` 缺省按 0.6 处理）。你把这 9000 颗的数组发我，或者把 json 放进项目里，我来接。

## 四、加照片（最重要）

把照片按下面四个文件名放进 `assets/img/`，**刷新页面就会自动出现**，不用改代码：

| 文件名 | 位置 | 建议尺寸 |
|---|---|---|
| `moon.jpg` | 观测档案 · 第一格 | 竖幅，约 1200×1400 |
| `sun.jpg` | 观测档案 · 第二格 | 横幅，约 1600×1100 |
| `site.jpg` | 观测档案 · 第三格 | 横幅，约 1600×1100 |
| `planets.jpg` | 观测档案 · 第四格 | 竖幅，约 1200×1200 |

- 图片会自动裁切填满画框（`object-fit: cover`），主体尽量放中间
- 单张控制在 **400 KB 以内**（可用 [squoosh.app](https://squoosh.app) 压缩）
- 图注在 `index.html` 搜「拍摄参数待补充」那一行 `<figcaption>` 里改
- 想加第五、六张：复制一整块 `<figure class="shot rv">`，改 `src` 与图注

现在四格是「暗格 + 虚线圆 + 标签」的占位，图片一放进去，占位层会自动隐藏。

## 六、加海报

海报是竖版 3:4。把图片放进 `assets/img/`，替换对应的一块：

```html
<figure class="poster rv">
  <div class="poster__frame">
    <img src="assets/img/poster-1.jpg" alt="2026 秋季招新海报">
  </div>
  <figcaption>2026 秋季招新</figcaption>
</figure>
```

再在 `style.css` 末尾补一条：

```css
.poster__frame img{position:absolute;inset:0;width:100%;height:100%;object-fit:cover;z-index:2}
```

## 八、小技巧

- `index.html?static` —— 关闭所有动画、定格在结束状态，用于截图或低性能设备演示
- `index.html?t=2.4` —— 把首屏定格在第 2.4 秒
- 页面尊重系统「减少动态效果」设置（`prefers-reduced-motion`），开启后直接显示完整画面
- 首屏动画在滚出视口或切到后台时自动暂停，省电
- 「今夜」区块的月相、日期、时间都是实时计算的，不用手动维护

## 九、技术说明

- 原生 HTML / CSS / JavaScript + 手写 WebGL2，无框架、无 CDN、无构建、无外部字体
- 字体用系统字体栈：中文标题走宋体（`Songti SC / 思源宋体 / SimSun`），正文走系统黑体
- 颜色：暖调近黑 `#131211`、米白 `#ece7dc`、单一强调色朱红 `#c0492e`
- 三张光路图是手写 SVG；光线从入射端到出射端逐条「生长」（Web Animations API），
  切换到另一结构时会重播，离开视野再滚回来也会重播
- 首屏要求浏览器支持 **WebGL2**（近两年的 Chrome / Edge / Safari 16+ / Firefox 都支持）；
  不支持时自动降级为纯黑背景 + 文字，不会白屏
- 兼容 Chrome / Edge / Safari / Firefox 近两年版本；不支持 IE
